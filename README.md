# APOII

Curso de Algoritmos y Programación II.

## Descripción

Programa en Java que simula un sistema básico bancario utilizando Programación Orientada a Objetos (POO) y herencia.

El sistema permite gestionar diferentes tipos de usuarios del banco, como clientes, empleados y un gerente principal, cada uno con funcionalidades específicas según su rol.

El programa utiliza interfaces gráficas mediante JOptionPane para la interacción con el usuario y está estructurado en múltiples clases que separan responsabilidades para lograr un diseño más organizado y mantenible.

Características del programa:

- Uso de clases y objetos.
- Implementación de herencia (Persona, Cliente, Empleado, Gerente).
- Aplicación de encapsulamiento con getters y setters.
- Separación de responsabilidades mediante clases de gestión:}
  - GestionarPersonas
  - GestionarClientes
  - GestionarEmpleados
  - GestionarGerentes
- Sistema de inicio de sesión con validación de credenciales.
- Menús dinámicos según el tipo de usuario.
- CRUD completo para clientes y empleados.
- Operaciones bancarias básicas:
  - Consulta de saldo
  - Depósitos
  - Retiros
- Generación de reporte general del banco.

Este ejercicio hace parte del aprendizaje de programación orientada a objetos en Java, aplicando conceptos como herencia, encapsulamiento, modularidad y organización del código en proyectos reales.
